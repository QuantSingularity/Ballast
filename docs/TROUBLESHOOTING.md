# Troubleshooting

| Symptom                                                            | Cause and fix                                                                                                                                                     |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API exits with "BALLAST_SECRET_KEY must be at least 32 characters" | Set one: `export BALLAST_SECRET_KEY="$(openssl rand -hex 32)"`, or run `scripts/setup_environment.sh` to create `.env`                                            |
| API exits mentioning demo seeding and the default demo password    | You are running staging or production with `BALLAST_SEED_DEMO_DATA=true`. Set `BALLAST_DEMO_PASSWORD` or disable seeding                                          |
| Demo users cannot sign in in production                            | By design: nothing is seeded outside development. Register the first account (it becomes Admin), then create others with `POST /api/auth/users`                   |
| `403 Self-registration is disabled`                                | The system already has users and registration is closed outside development. Ask an Admin, or set `BALLAST_ALLOW_SELF_REGISTRATION=true`                          |
| Web app shows "The server could not be reached"                    | The API is not running on port 5000, or you started `ng serve` without the proxy. Use `npx ng serve` from `web-frontend` (it reads `proxy.conf.json`)             |
| Web app signs out immediately                                      | The access token was rejected and the refresh failed, usually because `BALLAST_SECRET_KEY` changed. Sign in again                                                 |
| `423 Too many failed attempts`                                     | Five bad passwords for that email. Wait five minutes or restart the API (the lockout is in memory)                                                                |
| `429` on sign-in behind nginx or an ingress                        | The limiter sees the proxy's IP. Set `BALLAST_TRUST_PROXY=true` when a trusted proxy sits in front                                                                |
| Forecast returns 409 "No cash history"                             | No demo data (production-like environment). The system needs a data integration, see the architecture document                                                    |
| First forecast request is slow                                     | Models train lazily on first use (the RL agent takes about a second, forecasts a few hundred milliseconds). Results are cached afterwards                         |
| Numbers differ between runs                                        | They should not: data is deterministic for a given `BALLAST_AS_OF`. Without it, "today" moves daily and so does the history window                                |
| `ng test` fails with a Node version error                          | Angular 22 needs Node 22 or newer                                                                                                                                 |
| Android emulator cannot reach the API                              | Use `http://10.0.2.2:5000`, not `localhost`. Cleartext is allowed only for that host and `localhost`                                                              |
| MAUI host fails to build                                           | It was not compiled during development. See `mobile-frontend/Ballast.Mobile.App/README.md` for the fallback of generating a fresh template and copying four files |
| `dotnet format --verify-no-changes` fails                          | Run `scripts/lint_code.sh --fix`                                                                                                                                  |
